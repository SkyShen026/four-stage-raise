# 可复现执行规则 v1

本文件的量化定义为补充约定，并非已核实的交易员原版。修改参数时保留版本和参数快照。

## 拐点与时间

- 高拐点：High[i] 严格高于左右各2根 High；低拐点反向。相等极值默认不算拐点。一根K线同时满足高低拐点则跳过，因 OHLC 无法确定先后顺序。
- 拐点 i 仅在 i+2 收盘后可用。按确认时间顺序维护交替高低拐点；连续同类拐点只保留更极端者，相等保留较早者。修改只能影响之后的新结构，不修改历史信号。
- 对每个方向，最新完成的高低高或低高低三点为候选。空要求 A>C>B，多要求 A<C<B；B 须为 A 至 C 区间的最低/最高值，若存在更极端点则该候选不合格。这样不会从非极值点投影。
- C确认时建立候选，冻结锚点；同方向新三点候选确认时替换未入场旧候选。持仓使用原锚点直到退出，默认不加仓，每个标的最多一个仓位。
- 检查 C 到确认时点的完整K线：空若任何收盘>L(i)，多若任何收盘<L(i)，则结构已破坏。若 B 之后至确认时目标已经到达，也不发迟到信号。
- 不给“启动幅度”另设隐性门槛；若用户增加最小ATR幅度或高周期方向过滤，要标记为新参数，不事后优化。

## 指标

- 中轨 M(i) 为最后20根含当前完整K线的收盘价均值；σ为同窗口总体标准差；U=M+2σ，LB=M-2σ。
- TR=max(High-Low, abs(High-prevClose), abs(Low-prevClose))；ATR首值为14个有效TR的均值，之后 ATR=(13×前值+当前TR)/14。数据不足不填零。
- 所有锚点的布林带值使用锚点当时的数据，不能使用当前轨道替代。

## 收盘模式的状态机

1. 候选在 k=C确认K线收盘后可用。默认要求 C 满足主文件的中轨位置条件。
2. 对 t≥k：空触发 `Close[t-1]≥M[t-1] 且 Close[t]<M[t] 且 Close[t]≤L(t)`；多触发 `Close[t-1]≤M[t-1] 且 Close[t]>M[t] 且 Close[t]≥L(t)`。允许在 k 收盘同时确认并触发，交易仍只能在之后发生。
3. 每次先检查失效，再检查触发。等待期内出现结构收盘破坏、目标先到、价格触达当时 `C极值±max(0.25ATR[t],tick)` 的保护边界则取消；该等待期边界仅用于取消候选，入场后止损固定。
4. 最多等待 k 起10根完整K线（k至k+9）。到期无信号则过期，不继续追单。该期限为补充参数。
5. 触发后冻结 b、S、T。下一根开盘作为回测成交基准，加不利滑点。若开盘已越过S或T，或实际E重算后风险比不合格，则跳过。实时分析无成交回报只能称“待执行/执行条件”，不能当成持仓。
6. 一次候选最多一次入场，出场后等待新三点结构。已有仓位不因同向新候选调整原止损或目标；禁止扩大止损。

## 靠线模式（仅用户选用）

在 C确认后，完整K线的最高/最低范围与 `[L(t)-b,L(t)+b]` 相交，且空收盘≤L(t)、多收盘≥L(t)，视为测试趋势线后收回；下一根开盘才作为入场。其余风险、过期、退出规则相同。它是口述“接近趋势线入场”的可回测代理，不等于真实盘中市价入场。若用户要盘中版，须先固定触及定义并使用更细粒度数据，不能从日OHLC猜测盘中路径。

## 编号和时段

原述“第几个Raise”没有客观定义，默认不硬编码编号。只有用户提供明确波次或另行约定了计数规则时才记录；否则显示“趋势阶段未确定”，不声称已满足第一/第二次偏好。

默认日线不加开盘过滤。日内用户若要求避开纽约开盘，先确定其交易市场和具体窗口，考虑交易所时区与夏令时；不能把所有市场的纽约开盘都当作09:30。未确定窗口时说明未应用此过滤，不自行删掉交易。

## 数值核对案例（虚构价格）

- 空：A=(0,120)，B=(4,100)，C=(8,112)。L(i)=120-i；L(4)=116；D=16；T=84。若有效触发后 E=105、b=1，S=113，则毛收益风险比=21/8=2.625；c=0.5时净比值=20.5/8.5≈2.41。
- 多：A=(0,80)，B=(4,100)，C=(8,88)。L(i)=80+i；L(4)=84；D=16；T=116。E=95、b=1，S=87，毛比值同为2.625。
- 以上只验证几何及风险公式，不代表完整OHLC序列已满足入场条件。
- 若空单计划 E=85、S=113、T=84，则毛比值1/28，必须放弃，即使几何结构成立。

## 回测与绩效验证

仅用户要求回测时执行。先固定标的池、区间、周期、参数和模式，保存来源及数据快照。实现逐根推进的事件循环，枢轴须到确认时间才可用；使用复权一致数据，股票池注意幸存者偏差，期货处理换月与可交易合约。

信号在收盘形成、最早下一根成交；费用含佣金、价差和不利滑点，按需加入空头借券及资金费率。不能借到券的股票不开空。止损遇跳空按更差可成交价建模；日OHLC同根触及止损与目标且无更细数据时默认止损先发生并披露这一保守假设。结构收盘退出在下一开盘成交，期间保护止损仍有效。

分开报告开发样本与样本外结果：交易数、胜率、平均盈利/亏损、净期望R、利润因子、最大回撤、持仓时长、成本假设和参数敏感性；年化收益只有存在明确权益曲线、仓位和完整时段时才计算。少量交易不外推稳定性，不依据比赛成绩填补证据。用手工案例核对距离方向与风险比，用事件案例检验确认延迟、同根双触及、跳空和重复信号。
