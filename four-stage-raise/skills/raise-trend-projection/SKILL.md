# Raise 趋势线投影交易分析

将用户提供的口述策略转为可核对的交易计划。默认中文回答，明确区分开多、平多、开空、平空；“卖点”不能默认代表开空。

## 策略身份与边界

- 来源为用户提供的转述。“Raise”、人物姓名及赛事收益未经独立核实，不称为交易员官方规则，不以其收益证明有效。
- 原始核心：启动行情后等反弹/回调，用两个同侧拐点画趋势线；在中间极值所在K线测量价格与趋势线的垂直距离，再将该距离向趋势方向投影。布林带辅助筛选，优先趋势早期形态，计划盈利至少覆盖计划亏损。
- 本 skill 的拐点确认、缓冲、触发期限、费用处理、保护性止损等是为了复现而加入的执行约定，尚未证明具有盈利优势。首次应用应简短说明，不冒充原作者参数。
- 该方法是等幅几何投影，不自动等同斐波那契；布林带外侧不意味着必然反转。新闻热度和熟人询问仅为原述经验，不作为默认交易条件。
- 生成分析与交易计划；用户要求分析不意味着授权发送订单。

## 数据与默认设置

1. 确定标的、交易所、周期、分析截至时间和是否已有仓位。缺少标的时询问；未指定周期默认日线，用户指定短周期时遵从。周线/月线可辅助说明背景，不能用尚未收盘的大周期数据确认趋势。
2. 对“现在能否买卖”等实时问题，获取可用的可靠行情，披露来源、时间、时区、延迟和最后完整K线；工具不可得则请求 OHLC 数据或图表，不能用搜索摘要中的单个报价推算形态。
3. 数值分析至少需要覆盖锚点的完整 OHLC 和指标预热数据，优先最近200根完整K线。少于所需数据时只给可支持的结论。截图无精确价格/时间刻度时只标候选区域，不伪造小数精度。
4. 股票采用一致复权口径，价格与实际可交易报价应转换一致；期货披露合约、换月/连续合约调整方式和点值；日内注明交易时段。剔除未完成K线，检查缺失、重复和时序。
5. 默认参数：布林带20根收盘价 SMA、总体标准差 ddof=0、上下2σ；ATR(14) 使用 Wilder 平滑；拐点左右各2根；缓冲 b=max(0.25×ATR14, 1个最小报价单位)；最低扣费收益风险比1。这些数值中只有布林带常见默认值及收益风险比下限来自原述，其余为执行约定。
6. 默认只扫描每个方向最新的已确认连续三拐点结构，不回看挑选“画得最好”的锚点。严格机制见 [执行规则](references/execution.md)，实际计算、筛选、回测前读取。

## 分析流程

### 1. 识别已确认的结构

- 做空：高点 A → 低点 B → 更低高点 C，时间严格递增，C<A；通过 A、C 画下降线。
- 做多：低点 A → 高点 B → 更高低点 C，时间严格递增，C>A；通过 A、C 画上升线。
- 标出 A/B/C 的时间、价格与确认时间。C 尚未确认时只能“等待确认”。不能把未来才知道的拐点当成过去可用的信号。
- 无结构时直接判定“无有效形态”，不强行给买卖价。

### 2. 计算固定目标

以交易K线序号 i 为横轴，使用线性价格，不按截图角度测距：

`L(i) = P_A + (P_C-P_A) × (i-i_A)/(i_C-i_A)`

- 空：`D=L(i_B)-Low_B`；`T=Low_B-D`。
- 多：`D=High_B-L(i_B)`；`T=High_B+D`。

必须 D>0。目标是在 B 的时间位置测量，不能改成当前线值；不支持目标价的市场必须剔除不可交易目标。确认形态后锁定 A/B/C/D/T，不移动目标来掩盖失败。

### 3. 筛选位置、等待触发

- 默认做空要求 C 的高点≥该根布林带中轨；做多要求 C 的低点≤中轨。报告 C 与各轨的关系；不能据此声称胜率最高。
- 默认收盘确认模式：C 已确认后，空单等待收盘从中轨上方/等于中轨转到下方；多单反向。触发收盘仍须位于有效趋势线一侧，具体不等式见执行规则。
- 第一、第二个形态只作为有证据时的优先级；波次不可可靠编号时标“未知”，不编造。第四、第五个是原述衰竭提醒，不自动触发反向交易。
- 入场计划用触发K线收盘价估算，最早在下一根可成交时执行；实际开盘价偏离后重算风险比。不声称已经成交。
- 用户明确选择“靠线入场”时，按参考文件单独运行该模式，不能与收盘模式混算历史业绩。

### 4. 定义退出与风险

- 默认多单保护止损 `S=Low_C-b`；空单 `S=High_C+b`，b 在触发时固定。默认采用触价保护止损，这是对原述“等收盘止损”的明确修改。
- 同时保留结构退出：空单完整K线收盘上破 L(i)，多单收盘下破 L(i)，最早下一可成交时退出。保护止损、结构退出或目标，先发生者优先；不得等收盘取消已触发的保护止损。
- 用户要求原述收盘止损版时可分析，但标明它不限制盘中亏损，名义风险与实际损失可能不同；不得悄悄套用触价版回测结果。
- 多单要求 `S<E<T`；空单要求 `T<E<S`。设每单位往返费用/滑点估计为 c：`净潜在盈利=|T-E|-c`，`计划风险=|E-S|+c`，两者均需为正，净潜在盈利/计划风险≥1 才可通过。未知 c 时报告毛比值和费用未核实，不能宣称扣费后合格。
- 默认目标位全部退出；原述“让利润跑”在这里表示不随意提前平仓。分批、追踪止损或越过目标持有是另一个版本，只按用户要求启用。
- 有账户权益和用户风险预算时才算仓位：`数量=floor到合法交易单位(单笔风险预算/(|E-S|×点值+每单位往返成本))`，再检查现金、保证金、杠杆和组合约束。未提供预算不擅自推荐固定仓位。

## 输出约定

先给出结论：**无有效形态 / 等待确认 / 等待触发 / 已触发待执行 / 持仓管理 / 已失效 / 已到目标 / 数据不足**，并说明方向。已有仓位的退出不依赖出现一个相反方向的新开仓信号。

然后提供一张简洁表：标的与周期、行情截至时间、A/B/C与确认时间、趋势线公式、D、目标T、入场条件/估价E、保护止损S、结构退出条件、毛/净收益风险比、数据来源与未决条件。区分“有数据支持的事实”和“未来条件”，未知项明确留空或标注未知。

最后说明下一根或下一次分析应检查什么；若未触发，给条件价格/状态，不输出无条件“立即买入”。形态不能据此产生可靠成功概率；没有回测不要填写胜率、年化收益或“高胜率”评分。图表可用时标注锚点、趋势线、测量段和目标，坐标必须来自同一份数据。

批量筛选沿用同一组参数并记录数据截至时间；先剔除失效、未满足触发或风险条件的候选，再按净收益风险比等可测指标排序，不把排序解释为胜率。

- 若用户要求检验盈利能力，读取执行规则中的回测段，报告样本外表现及成本敏感性。技能文件通过格式检查不意味着策略有效。
