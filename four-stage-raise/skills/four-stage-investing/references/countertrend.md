# 可选：第四阶段反弹

仅在用户明确要求逆势反弹时采用，与长期低吸和第二阶段趋势仓分开记录。

1. 周线确认第四阶段，报告到30/40周线的实际偏离，不把偏离当作反弹概率或吸引力。
2. 切日线寻找反弹后的收紧平台。原口述未给日线四均线参数；分析前要求指定，或明确提出待验证的50/100/150/200日SMA研究约定。日线参数不是周线数值的精确替代，加密资产尤其如此。
3. 价格收复选用日线均线，在其上形成平台；明确平台开始、结束、高低边界和波动收缩证据。无平台则无信号，不能把急跌等同低吸。
4. 默认以日收盘突破已形成平台上沿作为候选触发，下一可交易时段评估执行。失效位在平台下沿以下，缓冲及风险预算事先定义。
5. 将200日线或更近阻力作为观察目标。若进场时200日线已在价格下方，不再是向上的反弹目标；若平台位于四线之上导致目标关系矛盾，报告该案例规则无法照搬，不制造交易。
6. 判断到目标的潜在收益是否覆盖到失效位的风险和成本。200日线会移动，不能保证价格回到过去某日的均线数值。
7. 在失效或目标触发时按反弹计划处理，不自动升级为长期持有。没有用户风险预算时只给条件计划和仓位公式。
