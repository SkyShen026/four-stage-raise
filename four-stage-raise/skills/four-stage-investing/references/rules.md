# 数据、阶段与执行规则

以下参数为可配置的初始研究约定，不是已验证的最优值。用户指定参数优先；每次分析保留参数口径，不能为了让某标的通过而临时改变。

## 数据

- 使用同一来源、一致拆股复权口径的OHLCV。说明是否处理现金分红；回测收益处理分红，成交价还原到当时可交易口径。不能混用复权收盘与未复权高低点来判断突破。
- 股票按交易所时区和交易周聚合，周收盘为该周最后交易日收盘。至少60根完整周K，最好104根以上以观察前序阶段。少于40周不生成完整四线判断；40–59周可展示可计算均线，但标记历史不足、无法充分确认阶段。
- SMA_n(t) = 最近n根完整周收盘价之和/n，n为10、20、30、40。未结束的本周仅作盘中预警，不能标为已确认周信号。
- 40周SMA与200日SMA覆盖时间近似，但采样不同，并不数值相等；加密资产一周7天，不能套用股票的5日换算。
- 周量与前20个完整周的平均成交量比较，基准不含当前周。无可靠量能时记为“未验证”，不因此伪造确认。
- 仅有截图时进行可见结构分析，数值标为估计；不能给出截图读不出的精确指标。

## 默认结构参数

| 参数 | 初始约定 |
|---|---|
| SMA方向 | d_n = SMA_n(t)/SMA_n(t-4)-1；>1%为向上，<-1%为向下，其余近似走平 |
| 方向敏感性 | 同时报出实际变化率；接近阈值说明判断敏感，不按阈值跳变宣称趋势必变 |
| 摆动高/低点 | 高点高于左右各2周高点，低点低于左右各2周低点；相等不计；到右侧第2周结束才确认 |
| HH/HL | 最近两个已确认摆动高点和低点均抬升；LH/LL为二者均下降 |
| 盘整区间 | 默认前12个完整周最高/最低价，不含信号周；可据已确认结构延长并披露边界 |
| 放量 | 信号周成交量≥前20周平均量的1.5倍，作为辅助，不赋予成功概率 |
| 均线缠绕 | 四线最大值/最小值-1≤5%，并且30/40周线走平；高波动标的可能需另行校准 |
| 突破 | 完整周收盘高于事先确定区间上沿；量能达标为放量突破，否则为突破但量能未确认 |

摆动结构不足时明确“结构未确认”。两点结构和均线只是筛选规则，不等于已验证的统计优势。

## 阶段决策

**第二阶段已确认**：完整周收盘 > SMA10 > SMA20 > SMA30 > SMA40，四线方向均向上，并有HH/HL。若价格突破底部、收复四线而排列或结构未完成，标为“1→2转换候选”，不能当完整第二阶段。原版保守趋势进场等完整确认；用户接受提前布局时，作为独立试仓条件标明。

**第四阶段已确认**：完整周收盘 < SMA10 < SMA20 < SMA30 < SMA40，四线均向下，并有LH/LL。其余明显转弱但不全满足的，标为“向第四阶段转换”或“下跌趋势、四线条件未完整”。默认不新增做多。

**第一阶段候选**：有前序下跌，30/40周线趋平，价格在区间中反复、近期不再持续创新低，均线逐步缠绕。不能仅因低位横盘断定底部完成。

**第三阶段候选**：有前序上涨，30/40周线趋平，HH/HL中断，价格在区间及均线间震荡，或发生可验证的突破失败。不能断定下一步必跌。

没有前序趋势或证据冲突时使用“过渡/不明确”。阶段可以跳转或恢复，不强制1→2→3→4。

## 买入与加仓

### A. 第二阶段回调：默认优先研究的低吸方式

1. 长期模式先通过质量复核且进入可接受估值区间；趋势模式不强制估值筛选，但标明未评估。
2. 前序第二阶段成立，30/40周线仍向上，最近已确认的重要周线低点尚未失守。短线排列暂乱时标“第二阶段回调、完整排列待恢复”。
3. 价格靠近事先选择的支撑区：前突破位、已确认周线低点或20/30/40周线区域。不能触线即视为买点。
4. 默认止跌触发：回调后首根完整周K收盘高于前一周高点，并重回选定支撑区上方。此触发是实现约定；不保证买到最低点。
5. 初始失效基于该次回调低点/支撑下沿，缓冲须明确金额或比例。若触发后已大幅高开，使到失效位的距离不符合风险预算，则取消或重新等待，不追单。

### B. 第一阶段向第二阶段突破

事先确定区间上沿，观察完整周收盘突破、收复四线、30/40周线不再下行与量能。条件未全满足时仅列候选。可选择突破确认后的下一交易时段，或其后回踩上沿再出现A中的止跌触发；明确本次采用哪种，不能事后择优。

长期模式底部试仓须质量、估值同时合格且用户接受该模式；不默认在持续第四阶段越跌越买。试仓规模仍受同一总持仓上限约束。

### 加仓

预先定义总仓位上限与分批计划；后续加仓须有新的结构确认，例如回踩成功或形成更高低点后再次突破。重新计算组合风险，不能因为成本下降而自动加仓。价格已明显远离支撑时，展示到失效位的百分比，让风险预算决定是否等待，不武断设置所有品种通用的追高距离。

## 卖出与失效

将三类事件分开：

1. **交易失效**：买点对应的回调低点/突破支撑失守。计划必须预先说明用盘中触发还是完整周收盘确认。短期或机动仓默认盘中风险止损；若选择周收盘，披露等待期间的额外下跌风险。
2. **趋势预警**：完整周收盘跌破30周线，或重要周线低点失守，或出现第三阶段候选。暂停加仓，复核，不宣称仅破10周线就是大顶。
3. **趋势退出确认**：默认连续2个完整周收盘低于40周线且30周线方向向下。趋势仓按预设计划退出剩余头寸；初始止损可能更早触发，不能为了等此条件而取消止损。

趋势模式可以在预警时部分减仓、确认时退出，具体比例事先选定并披露，不能声称某比例最优。

长期模式：机动仓可执行上述技术退出；核心仓依据预先写定的基本面失效条件、估值目标或持仓上限决定减仓退出。技术转坏触发重新评估；若用户要对全部仓位严格执行均线卖点，明确切换为趋势退出规则并在之后保持一致。不要把“优质”当作永不卖出的理由。

执行时点：周收盘信号通常在下一可交易时段执行；回测不得用尚未获知的收盘信号成交在同一收盘价。跳空可能超过计划损失，止损限价也可能不成交。

## 仓位

用户有风险预算则沿用。未提供时展示公式，不替用户假定风险承受能力或最大仓位：

允许股数 = min(单笔允许损失金额 ÷ (预计买入价−失效价+每股费用/滑点预留), 剩余持仓限额 ÷ 预计买入价)。

向下取可交易单位；分母必须为正。该公式是有止损计划的仓位模型，跳空仍可使实际损失超预算。长期核心仓不用价格止损时，改用持仓上限与情景回撤预算，不伪装成已锁定最大损失。

同一行业或主题的多只股票一起评估集中度，不能把高度相关标的视为独立风险。
