# 四阶段投资与买卖点

## 目标与模式

将用户提供的四阶段方法转为可执行的决策计划。核心是价格高低点结构、10/20/30/40周简单均线的排列和方向，以30/40周线为长期判断线。成交量用于辅助确认，基本面用于筛选标的。

默认使用**长期持有模式**：先验证企业质量和价格合理性，再用周线安排买入和减仓。用户明确要求原版策略、波段或趋势交易时，使用**趋势模式**。沿用已有持仓计划；不得在亏损后擅自从趋势模式改为长期模式。

- 长期模式：技术转弱触发暂停加仓、复核与预先约定的减仓；核心仓退出还结合投资逻辑、估值和集中度。若有核心仓/机动仓，应事先定义，不能事后给亏损仓位改名。
- 趋势模式：只在第二阶段寻找做多机会，以价格结构失效及趋势转坏退出。
- 第四阶段反弹是独立的可选策略。仅在用户要求时读取 [references/countertrend.md](references/countertrend.md)，不混入默认低吸计划。
- 不因第四阶段而自动建议做空；做空须另行评估。此skill产出分析及计划，不构成交易执行授权。

## 工作流程

1. 确认标的、交易所、分析日期和模式。已有持仓时使用已知成本、仓位和计划；资金或持仓未知仍可分析，用条件与比例表示，不虚构金额和股数。
2. 分析当前行情须取得可追溯的最新价格数据及基本面来源，明确最后完整周与最新交易日。数据不足则给出所缺内容和条件判断，不能编造均线、价位或阶段。
3. 读取 [references/rules.md](references/rules.md)，按统一口径计算SMA、方向、结构和阶段。输出已确认状态与潜在转换，允许“过渡/不明确”，不强行四选一。
4. 长期模式或选股任务读取 [references/quality.md](references/quality.md)。基本面合格、估值合适和技术买点分别判断，不互相替代。
5. 形成买入触发、失效条件、加仓条件、减仓/退出条件与仓位约束。阶段合格不等于当前价值得追买；价格远离支撑时等待条件改善。
6. 说明下一次什么价格或基本面变化会改变结论。筛选多个标的时，用同一日期和参数比较，披露股票池；不能将少量搜索结果声称为全市场扫描。

## 输出

默认中文。先用一句话给出“候选买入/等待确认/持有/暂停加仓/考虑减仓/退出条件触发/数据不足”，注明这是条件计划。随后提供：

| 项目 | 内容 |
|---|---|
| 数据与模式 | 来源、截至日期、完整周、复权口径、长期或趋势模式 |
| 当前阶段 | 阶段或过渡状态；价格结构、四线数值/排列/斜率证据 |
| 标的与估值 | 长期逻辑、主要反证、合理价格区间及假设；未评估则注明 |
| 买入/加仓 | 具体触发、确认周期、适用价格区域、不可追价的条件 |
| 风险与失效 | 初始失效价或条件、仓位计算、跳空/流动性影响 |
| 减仓/退出 | 预警与确认分开；长期核心仓和机动仓规则若适用 |
| 下一步 | 下次复核时间或事件、改变判断的证据 |

仅在数据支持时给精确价位。图表有助判断时展示周K与四条SMA、成交量及确认过的支撑阻力；不要求为了分析而生成装饰图。用户只要求简短判断时压缩表格，但保留触发与失效条件。

## 解释边界

- 这是用户口述方法的可执行化版本；量化阈值是实现约定，未经回测，不声称来自原作者或已有收益验证。
- 四条均线是相关的滞后价格指标，不是四份独立证据。阶段识别并不保证未来走势。
- 不把“好消息不涨”“坏消息不跌”“窄平台”直接解释为机构出货、吸筹或卖盘耗尽。
- 不使用“五八法则”生成概率，不因偏离均线很远推断必然反弹，不用精选成功案例证明有效。
- 不宣称专业交易者都不用其他指标；本策略保持SMA核心即可。
- 若用户要求验证效果，做包含失败案例、费用、滑点、退市样本和样本外区间的回测；对照买入持有及更简单的均线基线，报告回撤、换手、暴露时间和收益集中度。不能用尚未确认的周线或未来高低点回填历史信号。
