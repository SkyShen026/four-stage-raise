# 四阶段 × Raise 复合策略

结合周线市场周期、日线趋势投影与基本面估值，为长期持有者提供条件化的买入、持有、减仓和退出分析。

本仓库包含三个配套 Codex Skills，仅保存策略规则，不包含行情数据、回测程序或自动交易系统。

## 策略思路

通过三个层次依次判断：

| 层次 | 方法 | 回答的问题 |
|---|---|---|
| 长期配置条件 | 基本面质量与估值 | 标的是否值得长期持有，价格是否合理？ |
| 中期趋势 | 四阶段市场周期 | 当前是否允许新增风险？ |
| 短期买卖点 | Raise 趋势线等幅投影 | 何时触发，止损和目标在哪里？ |

基本面与估值未通过时，不将技术信号视为长期买入确认；周线环境不允许时，不因日线反弹而放宽入场条件。

## 包含的 Skills

### four-stage-investing

使用10、20、30、40周简单移动平均线（SMA），结合价格高低点结构，识别筑底、上升、筑顶与下跌阶段。

当条件不充分时，保留“过渡期”或“待确认”判断，不强行归类。

### raise-trend-projection

使用已确认的价格拐点建立趋势线，并通过等幅投影计算目标。

结合日线中轨交叉、保护止损、形态有效期和收益风险比，形成条件化交易计划。

### four-stage-raise

整合两个策略：

- 四阶段负责周线环境过滤。
- Raise负责日线入场与机动仓退出。
- 基本面与估值负责长期配置资格。
- 核心仓与机动仓分别管理。

具体公式、参数与失效规则以各 Skill 文件为准。


## 使用示例

### 分析单个标的

> 用 $four-stage-raise 分析 AAPL，按长期持有模式说明中期趋势、短期形态、条件买点、卖点和失效条件，并区分核心仓与机动仓。

### 比较多个标的

> 用 $four-stage-raise 分析 NVDA、AMD、MU、GOOGL 和 MSFT，区分禁止新增、等待形态、等待触发与技术已触发，并说明基本面和估值是否支持参与。

### 用于定时监测

> 每个美股交易日收盘后，使用 $four-stage-raise 检查观察名单。记录候选形态和有效期，仅在有效触发、形态失效、退出条件或重要基本面变化时提醒。

定时监测需要另外配置调度任务、行情来源及状态存储。上传或安装本仓库不会自动启动监测。

## 分析输出

分析应包含：

- 行情来源、数据截止时间及最近完整交易周。
- 基本面质量与估值判断。
- 周线阶段、均线方向和价格结构。
- 日线候选形态、确认日期及有效期。
- 条件买点、目标、止损和净收益风险比。
- 核心仓与机动仓各自的行动条件。
- 与上次分析相比的实质变化。

没有合格形态时，应明确写“等待”或“无有效买点”，不为了提供交易机会而放宽规则。

## 适用范围与边界

主要面向股票和ETF的周线、日线分析，不提供盘中实时止损服务。

指数可作为市场环境参考，不应直接视为可成交证券。黄金、原油等资产需要明确使用现货、期货或ETF口径，并单独分析产品结构和相关风险，不能机械套用公司盈利估值。

所有判断只使用当时已完成、已确认的数据。历史假设成交不代表用户实际持仓；机动仓到达Raise目标，也不意味着核心仓必须全部卖出。

## 验证与风险

本仓库提供分析规则，不提供经验证的稳定收益或胜率承诺。

组合策略需要独立回测，不能直接继承单策略的历史表现。信号过滤可能减少亏损，也可能错过上涨；交易样本过少时，胜率不具有可靠代表性。

止损价格不是保证成交价格，跳空、滑点、费用和流动性可能使实际结果偏离计划。本策略不自动下单，使用者需自行评估风险并作出决策。
